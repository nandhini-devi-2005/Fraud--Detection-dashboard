# Fraud--Detection-dashboard
Fraud Detection Analytics Dashboard is an end-to-end data analytics project developed to identify fraudulent financial transactions using SQL, Python, and Power BI.
The project demonstrates the complete analytics workflow—from data cleaning and SQL analysis to interactive dashboard creation—helping businesses monitor fraud patterns and make data-driven decisions.

This project was built to showcase practical Data Analytics skills including data preprocessing, exploratory data analysis (EDA), SQL querying, KPI creation, and dashboard development.
.

🎯 Objectives
Detect fraudulent transactions using transaction data that transaction occured between year 2019 -2020 and then it accounts 1852,394.
Analyze fraud trends across different transaction types.
Measure fraud rate and financial impact.
Build an interactive Power BI dashboard.
Generate actionable business insights for fraud prevention.
